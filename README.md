## 开始游戏

访问：https://pxz20100204.github.io/world-online-mvp/

在支持的 Chrome 或 Edge 中可从设置页安装到桌面或手机。安装后仍会优先检查 `app.js`、样式和数据文件的新版本，断网时回退到最近一次成功缓存；模型权重和场景音乐按需加载，不进入首屏缓存。

游戏进度保存在当前浏览器的本地存储中。更换设备或清除网站数据后会重新开始。聊天使用匿名玩家会话，消息会实时同步到其他在线玩家并保存在 Supabase 中。

金牛语模式支持直接输入既有金牛语，也支持从中文、英语、西班牙语、法语、德语、葡萄牙语、俄语、日语、韩语、阿拉伯语、印地语及其他 Unicode 文字转换。未收录词汇会生成稳定词根，并在消息下方保留原文。

## 游戏音乐

- 音乐默认开启；主城使用《Sela no Tora》，征战使用《Vara no Sela》，野局使用《Zhal no Vora》，叛军使用《Nava no Ashen》。
- 四首曲目按场景切换并按需下载，首次点击或按键后开始循环播放。
- 曲目采用 A 小调、72 BPM，包含柔和和弦、低音、雨声质感与金牛语元音合成吟唱。
- 设置页可以关闭或重新开启音乐，并查看六句金牛语歌词及中文译文；明确关闭后刷新页面仍保持关闭。

## 人口与领地生产

- 总人口扣除驻军后形成可用劳力，并按当前方案投入农业、商贸和征募。
- 农业负责粮食；人口和驻军每小时消耗粮食。盈余支持人口增长，粮仓耗尽后会停止征募并损失平民。
- 商贸产生金币，征募把平民转为驻军；征募不会凭空增加总人口，驻军最多占人口的 35%。
- 均衡、粮食优先、商贸优先和征募优先四种方案可以随时切换；切换前会结算旧方案的完整小时，避免回溯套利。
- 领地生产最多累计 12 小时。科技研究每级增加 8% 生产效率，人口和兵力同时成为村落晋升条件。

## AI 与叛军

- 小金牛仔不再使用关键词决策树生成回答，而是由 Qwen2.5 开源语言模型读取实时游戏快照后现场推理。
- 旗舰 3B、增强 1.5B、轻量 0.5B 三档模型由玩家明确选择；首次下载约 1.8 GB、900 MB 或 300 MB，之后缓存在浏览器。
- 推理通过 WebGPU 在玩家设备内完成，不调用 OpenAI 或其他 AI 推理 API，没有按次费用；只有首次安装模型需要联网下载静态文件。
- 游戏只向模型提供队伍、关卡、资源、人口、任务和叛军等结构化事实。模型只能建议跳转到白名单页面，不能修改存档、资源、战斗或聊天。
- 新设备默认推荐 1.5B 流畅档；需要更强分析时可手动切换 3B，低配设备可使用 0.5B。模型启动与回答速度取决于设备 GPU。
- 当前问题位于紧凑事实快照末尾；空正文自动重试一次。流式界面最多约每 90ms 更新一次，离开导引或网页进入后台会中断推理。
- 阿比盖尔会攻击玩家最依赖的金币、驻军、声望或主线节奏，预测直觉选择，并根据历史策略调整下一次行动。
- 新账号前三天只进行无损战术推演；保护结束后，叛军事件会真实影响金币、兵力、声望和情报。
- 每次事件结束后进入四小时情报冷却，防止通过重复事件无限获得奖励。

## 野局竞技

- 当前可玩模式为完整 1v1 单线野局，采用经典 MOBA 的兵线、外塔、基地、击杀、复活、等级、金币和技能冷却规则。
- 玩家从已拥有人物中选择英雄，并可指定人物之王使用完整英雄池中的任意英雄模板。
- 小兵每 8 秒刷新，防御塔优先攻击小兵；摧毁基地立即获胜，三分钟未结束则比较目标状态和击杀。
- 目标超出射程时，普攻、战技和必杀会锁定最近目标并自动接近，进入射程后立即施放；移动指令可取消追击。
- 人物之王每 400ms 最多决策一次，只评估推进、后撤、停留、普攻和三个技能，预测范围固定为 1.2 秒。
- AI 在独立线程运行，不能读取页面、存档、聊天或网络；超时会自动后撤，不会阻塞玩家界面。
- 渲染使用本地打包的 Phaser 3.90.0，并只在开始野局时按需加载；许可证位于 `vendor/PHASER-LICENSE.md`。

## 人物培养与副本

- 人物详情可以把等级重置为 Lv.1，并全额返还历次升级花费；星级、碎片和编队位置不变。
- 副本允许最多三人出战，每名存活人物每轮各行动一次，队伍行动完毕后 Boss 才出手。
- Boss 会提前显示单体或全体技能意图；AOE 分别对所有存活成员结算，稳守只为使用者提供减伤。

## 实时后端

- 浏览器仅使用 Supabase 可公开发布的客户端密钥。
- 消息表启用了行级安全策略，玩家只能以自己的匿名会话身份发送消息。
- 服务端限制同一玩家每 3 秒一条、每分钟最多 10 条消息。
- 数据库结构和安全策略位于 `supabase/schema.sql`。

## 本地 AI 许可证与来源

- 浏览器推理运行时使用 WebLLM 0.2.84（Apache-2.0），许可证位于 `vendor/WEBLLM-LICENSE.txt`。
- Qwen2.5 模型使用公开 MLC 量化版本，模型地址固定到具体提交；模型权重仅作为静态文件下载，不是远程推理服务。
- 三个模型对应的 WebGPU WASM 运行库随游戏同源发布，避免外部运行库主机波动导致安装卡住。
